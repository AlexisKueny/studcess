## 3 Equations et in´equations

Le domaine de d´efinition d'une ´equation (ou d'une in´equation) est l'ensemble des valeurs de l'inconue (ou des inconnues) pour lesquelles les deux membres sont d´efinis.

### 3.1 Equations

Pour r´esoudre une ´equation, on utilise :

```
1. a = b ⇔ a + c = b + c 2. si c ̸= 0, alors a = b ⇔ ac = bc 3. ab = 0 ⇔ a = 0 ∨ b = 0
```

### 3.2 Equation d'une droite

L'´equation y = ax + b, o`u a et b sont des param`etres et x et y les inconnues, poss`ede une infinit´e de solutions. Chaque solution (x, y) est un point d'une droite. a est sa pente et b son ordonn´ee `a l'origine.

La pente a de la droite passant par les points (x1, y1) et (x2, y2) est donn´ee par a = y2 - y1 x2 - x1 = ∆y ∆x . L'´equation de la droite de pente a passant par le point (x0, y0) est y = a(x - x0) + y0.

### 3.3 In´equations

Pour r´esoudre une in´equation, on utilise :

1. a &lt; b ⇔ a + c &lt; b + c
2. si c &gt; 0, alors a &lt; b ⇔ ac &lt; bc
3. si c &lt; 0, alors a &lt; b ⇔ ac &gt; bc

Autrement dit : c &gt; 0 ⇒ la multiplication par c conserve la direction de l'in´equation.

Autrement dit : c &lt; 0 ⇒ la multiplication par c change la direction de l'in´equation.

## 8 Polynˆomes

### 8.1 D´efinitions et propri´et´es

p(x) = n∑ k=0 akxk , avec an ̸= 0 est un polynˆome de degr´e n. On ´ecrit dgr(p(x)) = n. Il est d´efini par

n + 1 coefficients a0, a1, . . . , an. Il poss`ede au plus n z´eros.

###### Cons´equences :

1. Les n + 1 coefficients sont d´etermin´es par les valeurs du polynˆome en n + 1 points (polynˆome d'interpolation).
2. p(x) = q(x) ∀x ⇔ p(x) et q(x) ont les mˆemes coefficients (comparaison des coefficients).

### 8.2 Division

$$\frac { p ( x ) } { q ( x ) } = R ( x ) + \frac { r ( x ) } { q ( x ) } ,$$

o`u R(x) est le r´esultat et r(x) le reste de la division.

$$\text {dgr} ( R ( x ) ) = \text {dgr} ( p ( x ) ) - \text {dgr} ( q ( x ) ) , \quad \text {dgr} ( r ( x ) ) < \text {dgr} ( q ( x ) )$$

Si on divise par x - x0, alors r(x) = constante = p(x0). Il existe une m´ethode rapide pour une telle division (Horner).

### 8.3 Factorisation

## 9 Fonctions

### 9.1 D´efinitions et propri´et´es

```
Chaque x ∈ D(f) poss`ede exactement une image y. Notation : y = f(x). L'ensemble de toutes les images est not´e Im(f) (ensemble image). L'ensemble de tous les points (x, y = f(x)) forme le graphe de f.
```

Si chaque y ∈ Im(f) est l'image d'exactement un x, alors f est injective et poss`ede une fonction inverse, not´ee f -1.

On a alors : ∀x ∈ D(f), f -1(f(x)) = x et ∀y ∈ Im(f), f(f -1 (y)) = y.

```
g(f(x)) est not´e g ◦ f(x). C'est la composition de fonctions. Si f et g sont injectives, alors g ◦ f est aussi injective et (g ◦ f)-1 = f -1 ◦ g-1.
```

Une fonction f est paire si, ∀x ∈ D(f), f(-x) = f(x). Son graphe est sym´etrique par rapport `a l'axe des y.

Une fonction f est impaire si, ∀x ∈ D(f), f(-x) = -f(x). Son graphe est sym´etrique par rapport `a l'origine.

### 9.2 Translations et ´etirements

La courbe y = af(x) s'obtient par un ´etirement vertical de facteur a du graphe de f.

## 10 Limites

### 10.1 Notions de base

Si on utilise des fonctions continues, on calcule avec les limites comme avec des nombres, en y incorporant le concept d'∞, tant que les expressions sont d´efinies.

Exemples d'expressions d´efinies : ∞ · 3 = ∞, ∞ - 7 = ∞, 1 ±∞ = 0±, 1 0± = ±∞, 2∞ = ∞, ( 1 2 )∞ = 0

Pour des expressions ind´etermin´ees, il faut modifier leur repr´esentation pour les faire passer dans la cat´egorie des expressions d´efinies.

Exemples d'expressions ind´etermin´ees : 0 0 , ∞ ∞ , 0 · ∞, ∞ - ∞, 1∞, 00

### 10.2 Fonctions rationnelles

Une fonction f(x) = p(x) q(x) , o`u p(x) et q(x) sont des polynˆomes, est dite rationnelle.

Les z´eros de q(x) qui n'annulent pas p(x) sont les pˆoles de f(x). Ce sont les endroits o`u se trouvent les asymptotes verticales de f(x).

Si le degr´e de p(x) est suffisant, on peut faire la division. On obtient : f(x) = R(x) + r(x) q(x) .

Le r´esultat R(x) donne le comportement asymptotique de f(x) pour x → ±∞.

### 10.3 Asymptotes obliques

Si une fonction f(x) poss`ede une asymptote oblique d'´equation y = ax + b pour x → ∞, alors on peut calculer a et b ainsi :

$$\text {Perceptron} & \quad \text {and} \quad \text {a} = \lim _ { x \to \infty } \frac { f ( x ) } { x } \ e t \ b = \lim _ { x \to \infty } ( f ( x ) - a x ) . \\ \text {A} & \, \hat { m } \, \hat { e } m e \, \hat { m } \, \text {hodde pernet} \, \hat { e } g a l e m e n t \, d ^ { \prime } o b t e n$$

La mˆeme m´ethode permet ´egalement d'obtenir une ´eventuelle asymptote oblique pour x → -∞.

### 10.4 Prolongement par continuit´e

Soit f(x) une fonction qui n'est pas d´efinie en x0. Si lim x→x0 f(x) = y0, alors on peut prolonger f(x) par continuit´e en x0 en posant fprol(x0) = y0.

On peut d´emontrer que lim x→0 sin(x) x = 1. Autrement dit : la fonction f(x) = sin(x) x se laisse prolonger par continuit´e en 0 en posant fprol(0) = 1.
